# OnlyBody / OnlyWeights — дизайн перед імплементацією

Клікабельний редизайн обох iOS-застосунків. Дата: **31 жовтня 2026**. Погоджений напрям: м’який спортивний стиль, більші елементи, перебудова UX зі збереженням можливостей. Версію v002 погоджено користувачем як клікабельний прототип. Нова ітерація v003 реалізована для перегляду: вільна навігація, список підходів і компактний відпочинок.

## Відкрити

З кореня репозиторію:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory Design
```

Відкрити [дизайн-переглядач](http://127.0.0.1:8772/). Для порівняння: [v000 / v001](http://127.0.0.1:8772/?compare=true). Прямий перегляд без оболонки: [OnlyBody](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyBody), [OnlyWeights](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyWeights).

Сервер слухає лише цей комп’ютер. Посилання `127.0.0.1` на іншому телефоні не відкриє цей сервер. Для перевірки на iPhone потрібен окремий доступ із локальної мережі або перенесена копія прототипу; така перевірка ще не виконана.

## Керування переглядачем

- Версія, продукт, мова, екран, розмір, демосценарій і режим порівняння відображаються в URL. Посилання можна зберігати для повернення до того самого стану.
- «До / після» показує вибрану версію та версію з поля «Порівняти з» на 440 × 956. За замовчуванням це v001 та v002. Це базова геометрія еталонів. v001 та v002 окремо підтримують 375 × 812 та 393 × 852.
- «100%» означає один CSS-піксель на проєктний point. Це не гарантія однакового фізичного розміру на різних моніторах. «Вмістити» показує фактичний відсоток масштабу.
- Кожна панель має незалежний стан. Вибір екрана/сценарію з оболонки відновлює однакові початкові дані; натискання всередині панелі змінює лише її.
- Таймер зупинений за замовчуванням. «Живий таймер» запускає відлік. Скидання демоданих відновлює сценарій.
- Доступні стандартний сценарій, кілька тренувань сьогодні, день відпочинку, порожні дані, довга назва та помилка збереження заняття. Для останньої зручно відкрити «Завершення»; повторна спроба успішна.
- Додані екрани «Спосіб створення» та «Статистика». Для них v000 показує попередній еквівалент: вибір м’язів та журнал.

`baseline-checksums.json` містить SHA-256 збережених у Git файлів v000. Тести перевіряють їх перед запуском. Оригінальна папка `Release/Artifacts/UI-Baseline/2026-10-31` не змінюється; `_raw` не скопійовано.

Поточні рішення для обговорення записані в [v002/DECISIONS.md](versions/v002/DECISIONS.md). Попередні рішення залишилися у v001. Контрольні суми `v001-checksums.json` захищають її збережені у Git джерела та метадані. Після відгуку змінюємо конкретний рядок: **запропоновано / погоджено / відхилено**, дату та пояснення. Погодження напряму не означає погодження кожного екрана.

v002 погоджена й зафіксована. Кожну наступну завершену ітерацію фіксувати окремим Git-комітом. Наступні зміни — у v003 з посиланням на попередню версію. Не перезаписувати історичні звіти новими датами. При зміні спільного переглядача перевіряти, що зафіксовані версії зберегли вигляд; за потреби версіонувати й адаптер.

## Межі прототипу

SwiftUI, `Theme.swift`, репозиторії та SwiftData не змінені. Прототип використовує зафіксовані каталоги й демонстраційні дані v000; автопідбір, системні дозволи, нагадування, збереження та відео симулюються. Немає звернень до YouTube IFrame або нових відео. Початкові тексти згоди, автори, зовнішні посилання збережені; відеоблок перенесено нижче інформації про вправу.

Відео-чекліст `Scripts/ExerciseMedia/CHECKLIST.md` прочитаний для визначення меж. Перестановка HTML-блока не підтверджує ліцензії, фізичне відтворення чи готовність до App Review. Зміни нативного плеєра потребуватимуть окремого обов’язкового перегляду.

Браузерні mock-сесії мають лише локальні демонстраційні дані. Втрата цих даних після перезавантаження є очікуваною. Історія дизайну зберігається файлами й Git, а не localStorage браузера.

## Перевірка

За запущеного локального сервера:

```sh
node tests/verify-v002.cjs
```

Запускати з `Design`, використовуючи Node із доступним пакетом Playwright (`NODE_PATH` за потреби), та встановлений Google Chrome. Пакети не додаються до iOS-проєкту. `DESIGN_URL` дозволяє змінити адресу локального сервера.

Тести: контрольні суми v000; 2 продукти × 5 мов × 3 ширини × 18 екранів, додатково панелі; геометрія, зони натискання, палітра, створення/редагування, числове введення, підходи/відпочинок, збереження/повторна спроба, фільтри, одиниці ваги, нагадування та симуляція згоди на відео. Результат — [verification.json](versions/v002/verification.json). Знімки в `versions/v002/screenshots` мають ширину 393 CSS px, українську мову та зупинений таймер.

**Ще не перевірено:** фізичний iPhone, робота однією рукою, Safari на пристрої, нативна клавіатура, VoiceOver і системні жести. Це окремі критерії перед перенесенням у SwiftUI; браузерний PASS їх не замінює.

## Огляд тренування (v002)

Натиснути назву або верхню частину картки на головній. Огляд містить вправи в запланованому порядку, їхні параметри та основні м’язи; натискання вправи відкриває її опис. Унизу доступні редагування та запуск.

Акцент розраховується за кількістю запланованих підходів, у яких м’яз указаний основним у каталозі. Кожен підхід враховується один раз для кожної такої групи; суми різних груп можуть перевищувати загальну кількість підходів. Повтори й вага не використовуються для оцінки інтенсивності. Додаткові м’язи позначені окремим кольором на карті. Невідомі вправи залишаються в списку без вигаданих м’язових даних.

## Що зберігається в Git

Зберігаємо клікабельні джерела (HTML, CSS, JavaScript), необхідні runtime-ресурси (шрифти й зображення анатомії), документацію, метадані й текстові результати перевірок. Скриншоти в `versions/*/screenshots/`, історичні еталони в `versions/*/references/` та `studio.png` видалено також локально; ці шляхи ігноруються Git. Для запуску дизайн-переглядача вони не потрібні. Нова копія репозиторію працює без цих знімків; тести можуть згенерувати нові локально.

Посилання на скриншоти у старих manifest/verification описують історичні локальні докази, а не обов’язкові ресурси прототипу. Кнопка еталонного PNG в оригінальній автономній сторінці v000 потребує локального архіву; основний дизайн-переглядач порівнює клікабельні версії без PNG. Попередні Git-коміти зі скриншотами залишено як є, без переписування історії.

## v003 — сьогоднішнє заняття

Вибрати v003 у переглядачі або відкрити [OnlyBody](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyBody) / [OnlyWeights](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyWeights). Картка тренування та її кнопка запуску спочатку відкривають сьогоднішній список. До старту можна редагувати порядок і замінювати вправи; після старту повернення з вправи веде до списку без завершення заняття.

Вибір екрана «Відпочинок» у переглядачі показує компактну смугу над підходами. «Живий таймер» запускає демонстраційний відлік. Галочки й результати редагуються незалежно. Усі зміни заняття тимчасові; редактор шаблону зберігає зміни окремо.

[Рішення v003](versions/v003/DECISIONS.md), [результати перевірки](versions/v003/verification.json). Відтворення перевірки: `node Design/tests/verify-v003.cjs` із кореня, з доступним Playwright і локальним сервером. Підтримано п’ять мов. Нативна реалізація та фізичний iPhone не входять до браузерної перевірки.

Нативний сценарій v003 перенесено в обидва застосунки 1 листопада 2026. Поведінку, сумісність і межі перевірки описано в [IMPLEMENTATION.md](IMPLEMENTATION.md). HTML-джерела v003 залишено зафіксованими.

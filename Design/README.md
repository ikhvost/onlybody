# OnlyBody / OnlyWeights — дизайн перед імплементацією

Клікабельний редизайн обох iOS-застосунків. Дата: **31 жовтня 2026**. Погоджений напрям: м’який спортивний стиль, більші елементи, перебудова UX зі збереженням можливостей. Версію v002 погоджено користувачем як клікабельний прототип. Поточна пропозиція — **v006**, 3 листопада 2026: вирівняні іконки, окремі дії додавання та перегляду вправи, готовий відеоплеєр на початку гайда без попередньої картки згоди. Нативна реалізація залишається на v003.

## Відкрити

З кореня репозиторію:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory Design
```

Відкрити [дизайн-переглядач](http://127.0.0.1:8772/). Для порівняння: [v005 / v006](http://127.0.0.1:8772/?version=v006&compare=true&compare-base=v005). Прямий перегляд без оболонки: [OnlyBody](http://127.0.0.1:8772/runner.html?version=v006&product=OnlyBody), [OnlyWeights](http://127.0.0.1:8772/runner.html?version=v006&product=OnlyWeights).

Сервер слухає лише цей комп’ютер. Посилання `127.0.0.1` на іншому телефоні не відкриє цей сервер. Для перевірки на iPhone потрібен окремий доступ із локальної мережі або перенесена копія прототипу; така перевірка ще не виконана.

## Керування переглядачем

- Версія, продукт, мова, екран, розмір, демосценарій і режим порівняння відображаються в URL. Посилання можна зберігати для повернення до того самого стану.
- «До / після» показує вибрану версію та версію з поля «Порівняти з» на 440 × 956. За замовчуванням це v005 та v006. Це базова геометрія еталонів. v001 та v002 окремо підтримують 375 × 812 та 393 × 852.
- «100%» означає один CSS-піксель на проєктний point. Це не гарантія однакового фізичного розміру на різних моніторах. «Вмістити» показує фактичний відсоток масштабу.
- Кожна панель має незалежний стан. Вибір екрана/сценарію з оболонки відновлює однакові початкові дані; натискання всередині панелі змінює лише її.
- Таймер зупинений за замовчуванням. «Живий таймер» запускає відлік. Скидання демоданих відновлює сценарій.
- Доступні стандартний сценарій, кілька тренувань сьогодні, день відпочинку, порожні дані, довга назва та помилка збереження заняття. Для останньої зручно відкрити «Завершення»; повторна спроба успішна.
- Додані екрани «Спосіб створення» та «Статистика». Для них v000 показує попередній еквівалент: вибір м’язів та журнал.

Контрольні суми `v001-checksums.json` захищають її збережені у Git джерела та метадані. Після відгуку змінюємо конкретний рядок: **запропоновано / погоджено / відхилено**, дату та пояснення. Погодження напряму не означає погодження кожного екрана.

v002 погоджена й зафіксована. Кожну наступну завершену ітерацію фіксувати окремим Git-комітом. Поточні дизайн-зміни — у v006 з посиланням на v005; джерела v000–v005 збережені. Не перезаписувати історичні звіти новими датами. При зміні спільного переглядача перевіряти, що зафіксовані версії зберегли вигляд; за потреби версіонувати й адаптер.

## Межі прототипу

SwiftUI, `Theme.swift`, репозиторії та SwiftData не змінені. Прототип використовує зафіксовані каталоги й демонстраційні дані v000; автопідбір, системні дозволи, нагадування, збереження та відео симулюються. Немає звернень до YouTube IFrame або нових відео. Початкові тексти згоди, автори, зовнішні посилання збережені; відеоблок перенесено нижче інформації про вправу.

Відео-чекліст `Scripts/ExerciseMedia/CHECKLIST.md` прочитаний для визначення меж. Перестановка HTML-блока не підтверджує ліцензії, фізичне відтворення чи готовність до App Review. Зміни нативного плеєра потребуватимуть окремого обов’язкового перегляду.

Браузерні mock-сесії мають лише локальні демонстраційні дані. Втрата цих даних після перезавантаження є очікуваною. Історія дизайну зберігається файлами й Git, а не localStorage браузера.

## Перевірка

За запущеного локального сервера:

```sh
node tests/verify-v002.cjs
```

Запускати з `Design`, використовуючи Node із доступним пакетом Playwright (`NODE_PATH` за потреби), та встановлений Google Chrome. Пакети не додаються до iOS-проєкту. `DESIGN_URL` дозволяє змінити адресу локального сервера.

Тести: контрольні суми v000; 2 продукти × 5 мов × 3 ширини × 18 екранів, додатково панелі; геометрія, зони натискання, палітра, створення/редагування, числове введення, підходи/відпочинок, збереження/повторна спроба, фільтри, одиниці ваги, нагадування та симуляція згоди на відео. Результат — [verification.json](versions/v002/verification.json). Знімки в `versions/v002/screenshots` мають ширину 393 CSS px, українську мову та зупинений таймер.

**Ще не перевірено:** фізичний iPhone, робота однією рукою, Safari на пристрої, нативна клавіатура, VoiceOver і системні жести. Це окремі критерії перед перенесенням у SwiftUI; браузерний PASS їх не замінює.

## Огляд тренування (v002)

Натиснути назву або верхню частину картки на головній. Огляд містить вправи в запланованому порядку, їхні параметри та основні м’язи; натискання вправи відкриває її опис. Унизу доступні редагування та запуск.

Акцент розраховується за кількістю запланованих підходів, у яких м’яз указаний основним у каталозі. Кожен підхід враховується один раз для кожної такої групи; суми різних груп можуть перевищувати загальну кількість підходів. Повтори й вага не використовуються для оцінки інтенсивності. Додаткові м’язи позначені окремим кольором на карті. Невідомі вправи залишаються в списку без вигаданих м’язових даних.

## Що зберігається в Git

Зберігаємо клікабельні джерела (HTML, CSS, JavaScript), необхідні runtime-ресурси (шрифти й зображення анатомії), документацію, метадані й текстові результати перевірок. Скриншоти в `versions/*/screenshots/`, історичні еталони в `versions/*/references/` та `studio.png` видалено також локально; ці шляхи ігноруються Git. Для запуску дизайн-переглядача вони не потрібні. Нова копія репозиторію працює без цих знімків; тести можуть згенерувати нові локально.

Посилання на скриншоти у старих manifest/verification описують історичні локальні докази, а не обов’язкові ресурси прототипу. Кнопка еталонного PNG в оригінальній автономній сторінці v000 потребує локального архіву; основний дизайн-переглядач порівнює клікабельні версії без PNG. Попередні Git-коміти зі скриншотами залишено як є, без переписування історії.

## v003 — сьогоднішнє заняття

Вибрати v003 у переглядачі або відкрити [OnlyBody](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyBody) / [OnlyWeights](http://127.0.0.1:8772/runner.html?version=v003&product=OnlyWeights). Картка тренування та її кнопка запуску спочатку відкривають сьогоднішній список. До старту можна редагувати порядок і замінювати вправи; після старту повернення з вправи веде до списку без завершення заняття.

Вибір екрана «Відпочинок» у переглядачі показує компактну смугу над підходами. «Живий таймер» запускає демонстраційний відлік. Галочки й результати редагуються незалежно. Усі зміни заняття тимчасові; редактор шаблону зберігає зміни окремо.

[Рішення v003](versions/v003/DECISIONS.md), [результати перевірки](versions/v003/verification.json). Відтворення перевірки: `node Design/tests/verify-v003.cjs` із кореня, з доступним Playwright і локальним сервером. Підтримано п’ять мов. Нативна реалізація та фізичний iPhone не входять до браузерної перевірки.

Нативний сценарій v003 перенесено в обидва застосунки 1 листопада 2026. Поведінку, сумісність і межі перевірки описано в [IMPLEMENTATION.md](IMPLEMENTATION.md). Після наступних нативних уточнень HTML-прототипи v003 синхронізовано з `d812d78`: [перелік змін і браузерна перевірка](versions/v003/SYNC.md). Початковий звіт v003 збережено окремо; v000–v002 залишаються незмінними.

## v004 — Liquid Glass

Повний клікабельний прототип із темною нейтральною палітрою, системною типографікою та золотим акцентом. Плаваюча нижня навігація, круглі кнопки й компактний відпочинок використовують наближення скла; картки та числові поля мають щільні поверхні. Поведінка, каталоги, п’ять мов і демосценарії успадковані від v003.

«Менше руху» та «Менше прозорості» — демонстраційні перемикачі v004 у переглядачі. Вони зберігаються в URL як `reduce-motion=true` і `reduce-transparency=true`, передаються в пряме посилання та не змінюють попередні версії. Системні media preferences також враховуються. `no-blur=true` у прямому URL дозволяє перевірити суцільний fallback.

[Рішення й перевірки](versions/v004/DECISIONS.md), [токени](versions/v004/TOKENS.md), [повний звіт](versions/v004/verification.json). Це браузерна дизайн-пропозиція; SwiftUI та медіаінтеграція не змінені.

Команди з кореня репозиторію, за запущеного сервера та доступного host Playwright (`NODE_PATH` за потреби):

```sh
node Design/tests/verify-v004.cjs
DESIGN_VERSION=v004 DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/behavior-verification.json node Design/tests/verify-v003.cjs
DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/v003-regression.json node Design/tests/verify-v003.cjs
DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/v002-regression.json node Design/tests/verify-v002.cjs
```

Під час наступного прогону вказувати фактичну дату через `DESIGN_REVIEW_DATE`. Звіти попередніх версій не перезаписувати. Скриншоти v004 у `versions/v004/screenshots/` і `versions/v004/studio.png` — локальні, gitignored.

## v005 — уточнене керування

[Відкрити v005](http://127.0.0.1:8772/?version=v005) · [Порівняти деталі вправи](http://127.0.0.1:8772/?version=v005&compare=true&compare-base=v004&screen=movement&language=en).

Кругла кнопка лише з шевроном повертає назад; `×` закриває панель. Незастосовані параметри вправи, час і фільтри можна скасувати. Меню `…` містить заміну та переміщення вище/нижче; ручка перетягування залишається. Пошук і кнопка фільтрів стоять в одному рядку, нульовий лічильник приховано. Кнопки виконання підходів круглі з видимою галочкою, виконаний стан — золотий. Скорочені верхні відступи й пояснення.

[Рішення та межі перевірки](versions/v005/DECISIONS.md). Команди з кореня за запущеного сервера та доступного host Playwright:

```sh
node Design/tests/verify-v005.cjs
node Design/tests/verify-v005-controls.cjs
DESIGN_VERSION=v005 DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v005/behavior-verification.json node Design/tests/verify-v003.cjs
DESIGN_REPORT=Design/versions/v005/v004-regression.json node Design/tests/verify-v004.cjs
```

Дату поведінкового прогону задавати фактичною. v004 збережена разом із попередніми звітами; її тест тепер відкриває явний URL v004, оскільки початкова версія переглядача — v005. Кнопки зменшення руху/прозорості доступні для обох версій. Джерела v000–v004 захищені контрольними сумами v005; скриншоти локальні й gitignored.

## v006 — вибір вправ і відео

Рішення та команди перевірок: [v006/DECISIONS.md](versions/v006/DECISIONS.md). Іконки пошуку й меню вирівняні; `+` додає вправу, назва відкриває гайд із поверненням до списку. Відеоблок стоїть під назвою вправи. Одразу відображається макет плеєра зі звичайним Play, без картки згоди та Watch on YouTube. Блок YouTube у налаштуваннях прототипу також прибрано. Це лише перегляд дизайну: нативна згода й privacy policy залишені за підтвердженням користувача. Це зміна браузерного макета, без нових відео та без змін нативного плеєра.

# OnlyBody / OnlyWeights — дизайн перед імплементацією

Клікабельні дизайн-версії OnlyBody та OnlyWeights. Поточна версія — **v008**, 6 листопада 2026: Smart Selection v1 для рев’ю, поверх актуальної нативної бази. Реалізація Smart у застосунках — після погодження. v007 і попередні версії збережені. [Рішення та межі v008](versions/v008/DECISIONS.md), [вихідний план](versions/v008/SMART-SELECTION.md).

## Відкрити

З кореня репозиторію:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory Design
```

Відкрити [дизайн-переглядач](http://127.0.0.1:8772/). Для порівняння: [v007 / v008](http://127.0.0.1:8772/?version=v008&compare=true&compare-base=v007). Прямий перегляд без оболонки: [OnlyBody](http://127.0.0.1:8772/runner.html?version=v008&product=OnlyBody), [OnlyWeights](http://127.0.0.1:8772/runner.html?version=v008&product=OnlyWeights).

Сервер слухає лише цей комп’ютер. Посилання `127.0.0.1` на іншому телефоні не відкриє цей сервер. Для перевірки на iPhone потрібен окремий доступ із локальної мережі або перенесена копія прототипу; HTML у Safari на фізичному iPhone окремо не перевірявся; це не те саме, що нативна перевірка застосунків.

## Керування переглядачем

- Версія, продукт, мова, екран, розмір, демосценарій і режим порівняння відображаються в URL. Посилання можна зберігати для повернення до того самого стану.
- «До / після» показує вибрану версію та версію з поля «Порівняти з» на 440 × 956. За замовчуванням це v007 та v008. Це базова геометрія еталонів. v001 та v002 окремо підтримують 375 × 812 та 393 × 852.
- «100%» означає один CSS-піксель на проєктний point. Це не гарантія однакового фізичного розміру на різних моніторах. «Вмістити» показує фактичний відсоток масштабу.
- Кожна панель має незалежний стан. Вибір екрана/сценарію з оболонки відновлює однакові початкові дані; натискання всередині панелі змінює лише її.
- Таймер зупинений за замовчуванням. «Живий таймер» запускає відлік. Скидання демоданих відновлює сценарій.
- Доступні стандартний сценарій, кілька тренувань сьогодні, день відпочинку, порожні дані, довга назва та помилка збереження заняття. Для останньої зручно відкрити «Завершення»; повторна спроба успішна.
- Додані екрани «Спосіб створення» та «Статистика». Для них v000 показує попередній еквівалент: вибір м’язів та журнал.

## Огляд тренування (v002)

Натиснути назву або верхню частину картки на головній. Огляд містить вправи в запланованому порядку, їхні параметри та основні м’язи; натискання вправи відкриває її опис. Унизу доступні редагування та запуск.

Акцент розраховується за кількістю запланованих підходів, у яких м’яз указаний основним у каталозі. Кожен підхід враховується один раз для кожної такої групи; суми різних груп можуть перевищувати загальну кількість підходів. Повтори й вага не використовуються для оцінки інтенсивності. Додаткові м’язи позначені окремим кольором на карті. Невідомі вправи залишаються в списку без вигаданих м’язових даних.

## Що зберігається в Git

Зберігаємо клікабельні джерела (HTML, CSS, JavaScript), необхідні runtime-ресурси (шрифти й зображення анатомії), документацію, метадані й текстові результати перевірок. Скриншоти в `versions/*/screenshots/`, історичні еталони в `versions/*/references/` та `studio.png` видалено також локально; ці шляхи ігноруються Git. Для запуску дизайн-переглядача вони не потрібні. Нова копія репозиторію працює без цих знімків; тести можуть згенерувати нові локально.

Посилання на скриншоти у старих manifest/verification описують історичні локальні докази, а не обов’язкові ресурси прототипу. Кнопка еталонного PNG в оригінальній автономній сторінці v000 потребує локального архіву; основний дизайн-переглядач порівнює клікабельні версії без PNG. Попередні Git-коміти зі скриншотами залишено як є, без переписування історії.

## v004 — Liquid Glass

Повний клікабельний прототип із темною нейтральною палітрою, системною типографікою та золотим акцентом. Плаваюча нижня навігація, круглі кнопки й компактний відпочинок використовують наближення скла; картки та числові поля мають щільні поверхні. Поведінка, каталоги, п’ять мов і демосценарії успадковані від v003.

«Менше руху» та «Менше прозорості» — демонстраційні перемикачі v004 у переглядачі. Вони зберігаються в URL як `reduce-motion=true` і `reduce-transparency=true`, передаються в пряме посилання та не змінюють попередні версії. Системні media preferences також враховуються. `no-blur=true` у прямому URL дозволяє перевірити суцільний fallback.

[Рішення й перевірки](versions/v004/DECISIONS.md), [токени](versions/v004/TOKENS.md), [повний звіт](versions/v004/verification.json). Це браузерна дизайн-пропозиція; SwiftUI та медіаінтеграція не змінені.

Команди з кореня репозиторію, за запущеного сервера та доступного host Playwright (`NODE_PATH` за потреби):

```sh
node Design/tests/verify-v004.cjs
DESIGN_VERSION=v004 DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/behavior-verification.json node Design/tests/verify-v003.cjs
DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/v003-regression.json node Design/tests/verify-v003.cjs
DESIGN_REVIEW_DATE=2026-11-03 DESIGN_REPORT=Design/versions/v004/v002-regression.json node Design/tests/verify-v002.cjs
```

Під час наступного прогону вказувати фактичну дату через `DESIGN_REVIEW_DATE`. Звіти попередніх версій не перезаписувати. Скриншоти v004 у `versions/v004/screenshots/` і `versions/v004/studio.png` — локальні, gitignored.

## v005 — уточнене керування

[Відкрити v005](http://127.0.0.1:8772/?version=v005) · [Порівняти деталі вправи](http://127.0.0.1:8772/?version=v005&compare=true&compare-base=v004&screen=movement&language=en).

Меню `…` містить заміну та переміщення вище/нижче; ручка перетягування залишається. Пошук і кнопка фільтрів стоять в одному рядку, нульовий лічильник приховано. Кнопки виконання підходів круглі з видимою галочкою, виконаний стан — золотий. Скорочені верхні відступи й пояснення.

## v006 — вибір вправ і відео

Рішення та команди перевірок: [v006/DECISIONS.md](versions/v006/DECISIONS.md). Іконки пошуку вирівняні; `+` додає вправу, назва відкриває гайд із поверненням до списку. ### Синхронізація v006 з нативними змінами — 3 листопада 2026

Макети OnlyBody та OnlyWeights відтворюють прямі кнопки заміни з `7a4b5c7`: дві вертикальні стрілки замість `…`, без панелі Move Up / Move Down. SVG повторює геометрію `ReplaceIcon` (24 px, штрих 1,8), кругла кнопка має 44 × 44 px і фон `surface2`. Ручка — шість крапок із `ReorderIcon`, 20 px усередині цілі 44 × 44 px. Перетягування збережене; клавіші ↑/↓ на ручці відтворюють нативну adjustable-дію без додаткових видимих кнопок.

# v005 — токени уточнення

Матеріали, палітра й системні шрифти збережені з [v004](../v004/TOKENS.md). Джерело істини v005 — `styles.css`.

| Елемент | Рішення |
|---|---|
| Back / Close | 44 × 44 px, шеврон / хрестик без видимого тексту, нейтральний колір |
| Картка вправи | Відступ 12 px, назва 17 px, допоміжний текст 13 px; ручка та `…` мають цілі від 44 px |
| Меню дій | Нижня панель, рядки від 52 px, власна назва вправи й Close |
| Пошук | Гнучка ширина поля + кнопка фільтрів 52 × 52 px |
| Підходи | Колонка виконання 64 px, кругла кнопка 48 × 48 px, підпис 13 px |
| Верхні відступи | 12 px від панелі керування до контенту; без додаткового відступу над назвою вправи |

Геометрія іконок не залежить від мови; локалізовані назви залишаються доступними для допоміжних технологій. Токени SwiftUI не змінювалися.

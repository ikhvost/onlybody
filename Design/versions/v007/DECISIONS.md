# v007 — поточний нативний Liquid Glass

Дата: 5 листопада 2026. Продукти: OnlyBody та OnlyWeights.

Нова версія відтворює поточну спільну реалізацію SwiftUI. v006 та попередні версії залишені без змін; контрольні суми збережено в `baseline-checksums.json`.

- Системний `TabView` із трьома вкладками: тренування, журнал, вправи. Нативні символи: `figure.strengthtraining.traditional`, `clock.arrow.circlepath`, `books.vertical`. HTML показує наближені SVG-іконки та матеріал, а не справжні SF Symbols чи системний таббар. Вкладки доступні лише на кореневих екранах; перемикання — кнопками таббара.
- Круглі скляні Back / Close / Settings; золота скляна кнопка створення. Заголовок центрується відносно всього екрана з однаковим місцем для кнопок зліва й справа.
- Скляні нижні дії: збереження тренування, підтвердження вибору м’язів у редакторі та редагування вправи. Прозора підкладка; прокручування залишається доступним над кнопкою.
- Режим тренування можна вибирати лише під час створення. Під час редагування перемикач відсутній, а зміна режиму заблокована також у поведінці прототипу й ViewModel.
- Дні тренувань, тривалість Smart і відпочинок доступні одразу, без Schedule / Workout options акордеонів. Для ручного режиму немає цільової тривалості.
- Картки, палітра, типографіка контенту, фільтри й таймер збережені. Відео та його інтеграцію не змінено.

## Джерела та межі

SwiftUI — джерело істини для системних компонентів. CSS не відтворює рефракцію, анімації та адаптацію системного матеріалу iOS. Браузерний PASS не замінює перевірку нативної доступності.

У прототипі залишені демонстраційні дані історичної бази; він не імпортує особисті тренування з телефона й не відкриває реальний YouTube-плеєр.

Браузерні результати — `verification.json`. Нативні перевірки та фізичний iPhone — `NATIVE.md`. Знімки зберігаються локально в ігнорованому Git каталозі `references/`; вони не потрібні для роботи клікабельного переглядача.

# v007 — нативні компоненти

Палітра й типографіка контенту залишилися з v006 / `Theme.swift`.

- Нативний таббар повністю визначається iOS: матеріал, підписи, розміри, виділення. Акцент — `Theme.accent`. У HTML використана окрема наближена капсула 320 CSS px, три рівні кнопки та системний шрифтовий стек.
- Нативні навігаційні кнопки використовують `.glass` і `.circle`. HTML резервує 58 CSS px під кнопку з її зовнішніми системними відступами; внутрішня ціль SwiftUI — щонайменше 44 pt.
- Хедер: рівні бічні колонки, центрований текст 20 px / bold; довгі переклади переносяться без зміщення від центру.
- `GlassActionButton`: `.glassProminent`, золотий акцент, капсула, мінімальна висота вмісту 52 pt. HTML показує наближену зовнішню висоту 66 CSS px, враховуючи відступи стилю.
- Секції редактора: відкриті дні тренувань із проміжком 8 px; відступ перед розкладом 16 px, перед тривалістю / відпочинком 14 px.
- Нативні Reduce Motion / Reduce Transparency контролюються iOS. У браузері збережені попередні демонстраційні перемикачі матеріалу та руху.

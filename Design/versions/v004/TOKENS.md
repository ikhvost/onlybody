# v004 — візуальні токени

Джерело істини нової палітри, типографіки та матеріалу — `styles.css`. `layout.css` зберігає геометрію сценаріїв v003; новий шар перевизначає її для v004.

| Група | Значення |
|---|---|
| Фон / картка / вкладена поверхня | `#0B0B0D` / `#1C1C1E` / `#2C2C2E` |
| Текст / допоміжний / другорядний | `#F5F5F7` / `#C3C3CA` / `#A4A4AD` |
| Акцент / небезпечна дія | `#E8A23A` / `#FF9C94` |
| Скляний матеріал | Тонування `#202024EB`, blur 24 px, saturation 1.35, світлий край і м’яка тінь |
| Суцільний fallback | `#303034`; панель `#202024` |
| Типографіка | `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif` |
| Шкала | Основний 17, допоміжний 15, картка 20, заголовок 34, вправа 28, вкладка 12 px |
| Числа | Системний шрифт, `tabular-nums` у полях, таймерах та показниках |
| Відступи | 4 / 8 / 12 / 16 / 20 / 24 / 28 px |
| Округлення | Картка 24, поле 14, панель 32 px; капсула 999 px |
| Керування | Мінімальна ціль 44, степпер 48, основна кнопка 52 px |
| Навігація | Мінімальна висота 68, вкладка 58, запас прокрутки 112 px; нижній відступ ≥24 px з safe-area |
| Рух | Натискання 160 ms, поява панелі 240 ms; без анімацій у Reduce Motion |

`reduce-transparency=true`, системний `prefers-reduced-transparency` та відсутність підтримки `backdrop-filter` дають суцільні матеріали. `no-blur=true` відтворює fallback для QA. `reduce-motion=true` враховується також JavaScript-анімацією перетягування, а не лише CSS.

Ці токени не змінюють `Theme.swift` і не означають погодження нативної реалізації.

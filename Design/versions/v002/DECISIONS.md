# v002 — зміни після відгуку

Дата: 2026-10-31. Батьківська версія: v001. Статус конкретного оформлення: **погоджено користувачем**. Версію v002 зафіксовано як клікабельний прототип; наступні зміни дизайну — у v003. SwiftUI та дані застосунків не змінені.

|---|---|---|---|

| D16 | Показувати три показники й карту активності безпосередньо в журналі | Прямий запит користувача; замінює D13 з v001 | Погоджено |

| D18 | В огляді показувати вправи, параметри, основні м’язи та карту м’язів | Прямий запит користувача | Погоджено |
| D19 | Ранжувати основні групи за кількістю запланованих підходів | Прозорий підрахунок з наявного каталогу; не фізіологічна оцінка навантаження | Погоджено |

У верхньому блоці акценту показуються всі групи з найбільшою кількістю підходів (включно з однаковими результатами). Нижче є повний список із кількостями та поясненням методу. На карті основні групи золоті, додаткові — блакитні. Вправи з кількома основними групами враховуються для кожної групи. Дані перераховуються після редагування тренування.

Кнопки редагування та запуску на головній залишаються окремими діями й не відкривають огляд випадково. З опису вправи повернення веде до огляду. Порожні або недоступні тренування обробляються без підстановки іншого тренування.

v000 та v001 збережені без змін. Переглядач може порівнювати v002 із кожною з них; для нового екрана огляду попередні версії показують головний екран, звідки починається сценарій.

Скриншоти зберігаються локально й не входять у поточний Git-знімок. У Git залишаються HTML, CSS, JavaScript, необхідні шрифти й анатомічне зображення, метадані та документація. Попередні коміти не переписуються.

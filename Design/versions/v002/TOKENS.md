# Токени v002 → майбутній Theme

Це специфікація для подальшого SwiftUI-перенесення. `Theme.swift` зараз не змінений. Значення — кінцеві point/CSS px; множник `typographyScale` до них не застосовувати.

| CSS | Значення | Призначення / майбутній токен |
|---|---|---|
| `--bg` | #10110F | Theme.bg |
| `--surface` / `--surface2` | #1B1D19 / #242720 | Theme.surface / surface2 |
| `--text` / `--text2` / `--text3` | #F5F0E8 / #B9B6AE / #96938B | Основний / допоміжний / приглушений текст |
| `--accent` | #E8A23A | Theme.accent |
| `--danger` | #FF9689 | Читабельний текст руйнівної дії |
| `--type-body` / `--type-meta` | 18 / 15 | Основний текст / підписи |
| `--type-card` / `--type-heading` | 20 / 32 | Назви карток / заголовки екранів |
| `--type-exercise` / `--type-number` | 28 / 40 | Активна вправа / числові поля |
| `--type-timer` | 80 | Таймер відпочинку |
| `--touch` / `--step` | 44 / 48 | Мінімальна зона / степер |
| `--button` / `--complete` | 56 / 64 | Основна кнопка / завершення підходу |
| `--inset` / `--card-inset` / `--section-gap` | 20 / 16 / 24 | Зовнішнє поле / картка / секції |
| `--radius` / `--button-radius` | 16 / 12 | Картки / кнопки |

Головна дія: золота заливка + темний текст. Другорядна: темна поверхня, світлий текст і видима межа. Вибір: золота межа/текст та тонована поверхня. Не використовувати лише колір для передачі вибору.

Контраст усіх п’яти текстових кольорів перевіряється на трьох основних поверхнях. Найслабша пара серед основних текстових токенів — `text3 / surface2`, приблизно 4.94:1.

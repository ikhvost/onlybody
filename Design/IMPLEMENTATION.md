# Нативне перенесення v002

Дизайн v002 перенесено у спільні SwiftUI-екрани OnlyBody та OnlyWeights. Погоджені HTML-версії залишилися незмінними. Нативне ручне приймання на iPhone ще очікує перевірки.

## Реалізовано

- Палітра, кінцеві розміри тексту без множника 1.1, радіуси й відступи v002. Основні кнопки 56 pt, завершення підходу 64 pt, степери 48 pt, інші власні кнопки від 44 pt. Підказки текстових полів також використовують контрастні токени.
- Групи «Сьогодні» / «Інші тренування», «+» біля налаштувань і окремі дії огляду, редагування та запуску.
- Огляд шаблону за ID, упорядковані вправи, рейтинг основних м’язів за запланованими підходами, однакові максимуми, додаткові групи й анатомічна карта. Метод підрахунку пояснено текстом.
- Ручне створення та автопідбір. Компактні картки редактора, нативна панель параметрів, підтвердження видалення, згорнуті розклад / параметри, закріплене збереження та захист чернетки.
- Велике числове введення повторів / ваги, kg/lb, умовна вага OnlyBody, відпочинок, опис / історія, фактичний результат і повторне збереження з тим самим ID сесії.
- Заняття без завершених підходів не записується в журнал. Завершений підхід із нульовими повторами враховується як завершений.
- Незалежні фільтри бібліотеки й вибору вправ, один список із рівнем складності в рядку. Статистика та карта активності залишаються над історією журналу.
- Спільна типографіка деталей заняття, історії, налаштувань і нагадувань. Нові тексти мають переклади uk / en / pl / de / fr; застосунки використовують мову iOS.

## Сумісність і нативна поведінка

Збережено View → ViewModel → repository protocol. Огляд отримує ViewModel через AppComposition; підсумок м’язів — чистий сервіс із detached-результатом. SwiftData-схема, ідентифікатори моделей, seed stores, каталоги, ключі налаштувань і Bundle ID не змінені. Нових залежностей немає.

Автопідбір використовує попередній генератор і продуктові політики. Збереження не генерує програму повторно без зміни конфігурації та зберігає відредаговані параметри.

Нативні sheets, клавіатури й підтвердження оформлені токенами v002. Підходи / планові повтори ≥ 1, фактичні повтори ≥ 0, індивідуальний відпочинок ≥ 15 с. Цілі значення обмежені Int32 для відхилення переповнення. Вага ≥ 0, до двох десяткових знаків із локальним роздільником; зберігається в kg. Помилковий текст не застосовується й блокує завершення / перехід, залишаючись доступним для виправлення.

Завершення підходу прибирає числові поля перед показом відпочинку. Збережено інтерактивне закриття клавіатури прокручуванням і Return із зовнішньої клавіатури. Горизонтальний жест назад поглинає дотик до картки перед підтвердженням втрати чернетки. Нове натискання вкладки виконується під час попередньої анімації; стара анімація не скидає стан новішої.

Середовище: Xcode 27.1, Swift 6.4, iOS Simulator 26.4.1. Основний повний прогін — ширина 375 pt. Перевірена реалізація зафіксована в коміті `4ae6919` та його попередниках.

| OnlyWeights | PASS: 255 / 255 тестів, з них 244 Swift Testing і 11 XCTest UI |
| Release обох schemes | PASS, arm64 / x86_64 Simulator |
| Архітектурні межі, каталоги, локалізації, SwiftLint | PASS |

Пройдено п’ять E2E-сценаріїв кожного продукту: створення / перезапуск, редагування, завершення / історія, дострокове завершення, навігація. Вони перевіряють також пряме введення, порожнє число й виправлення, kg/lb, перехід від клавіатури до відпочинку, нуль завершених підходів, захист чернетки та видалення шаблону зі збереженням історії. Помилка запису й повторна спроба без дубля перевірені mock-репозиторіями; rollback — інтеграційними тестами.

`Scripts/validate.sh` виконав тести та Release-збірки обох продуктів успішно. Після збірок запуск зупинився на EOF під час паралельного редагування цього файла іншою роботою. Решту його кроків — app bundles і генерацію обох seed stores — виконано окремо успішно. Поточний файл проходить `bash -n`; це не запис про єдиний запуск скрипта з exit 0.

Локальні результати: `/tmp/onlybody-v002-validation/onlybody-Tests.xcresult`, `/tmp/onlybody-v002-validation/onlyweights-Tests.xcresult`, журнал `/tmp/onlybody-v002-validation-acceptance.log`, завершальні кроки `/tmp/onlybody-v002-postflight.log`.

## Візуальна матриця й межі перевірки

Пройдено нативну галерею 20 екранів / панелей × 5 мов × ширини 375 / 393 / 440 pt для обох продуктів. Використано 375 × 667, 393 × 852 і 440 × 956 pt; найменший екран суворіший за високий телефон мокапів. Після уточнення кольору підказок повторено повну матрицю 375 pt й вибірково переглянуто знімки. Візуальний огляд вибірковий; автоматичного pixel-diff із HTML немає.

Галерея доступна лише у DEBUG з явним прапорцем і UUID тестового простору. Вона використовує preview-репозиторії, фіксовані стресові дані й заморожені таймери, не відкриваючи live store. Нижній службовий рядок займає додаткові 44 pt. Реальні навігаційні переходи, клавіатуру та safe area перевіряють звичайні E2E-сценарії. PNG / xcresult зберігаються тимчасово поза Git.

Під час фінального прогону в робочому дереві з’явилися паралельні зміни локалізації, місяців журналу та їхніх перевірок. Вони не перезаписуються й не включаються до комітів цього перенесення; результати повного прогону стосуються зібраного ним стану. Додатково на поточному робочому дереві пройшли LogViewModelTests + SessionBuilderViewModelTests (37 тестів на кожен продукт) і оновлений локалізаційний smoke-тест усіх п’яти мов в обох продуктах.

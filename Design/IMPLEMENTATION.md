# Нативне перенесення v002

Дизайн v002 перенесено у спільні SwiftUI-екрани OnlyBody та OnlyWeights. Погоджені HTML-версії залишилися незмінними. Нативне ручне приймання на iPhone ще очікує перевірки.

## Реалізовано

- Палітра, кінцеві розміри тексту без множника 1.1, радіуси й відступи v002. Основні кнопки 56 pt, завершення підходу 64 pt, степери 48 pt, інші власні кнопки від 44 pt. Підказки текстових полів також використовують контрастні токени.
- Групи «Сьогодні» / «Інші тренування», «+» біля налаштувань і окремі дії огляду, редагування та запуску.
- Огляд шаблону за ID, упорядковані вправи, рейтинг основних м’язів за запланованими підходами, однакові максимуми, додаткові групи й анатомічна карта. Метод підрахунку пояснено текстом.
- Ручне створення та автопідбір. Компактні картки редактора, нативна панель параметрів, підтвердження видалення, згорнуті розклад / параметри, закріплене збереження та захист чернетки.
- Велике числове введення повторів / ваги, kg/lb, умовна вага OnlyBody, відпочинок, опис / історія, фактичний результат і повторне збереження з тим самим ID сесії.
- Заняття без завершених підходів не записується в журнал. Завершений підхід із нульовими повторами враховується як завершений.
- Незалежні фільтри бібліотеки й вибору вправ, один список із рівнем складності в рядку. Статистика та карта активності залишаються над історією журналу.
- Спільна типографіка деталей заняття, історії, налаштувань і нагадувань. Нові тексти мають переклади uk / en / pl / de / fr; застосунки використовують мову iOS.

## Сумісність і нативна поведінка

Збережено View → ViewModel → repository protocol. Огляд отримує ViewModel через AppComposition; підсумок м’язів — чистий сервіс із detached-результатом. SwiftData-схема, ідентифікатори моделей, seed stores, каталоги, ключі налаштувань і Bundle ID не змінені. Нових залежностей немає.

Автопідбір використовує попередній генератор і продуктові політики. Збереження не генерує програму повторно без зміни конфігурації та зберігає відредаговані параметри.

Нативні sheets, клавіатури й підтвердження оформлені токенами v002. Підходи / планові повтори ≥ 1, фактичні повтори ≥ 0, індивідуальний відпочинок ≥ 15 с. Цілі значення обмежені Int32 для відхилення переповнення. Вага ≥ 0, до двох десяткових знаків із локальним роздільником; зберігається в kg. Помилковий текст не застосовується й блокує завершення / перехід, залишаючись доступним для виправлення.

Завершення підходу прибирає числові поля перед показом відпочинку. Збережено інтерактивне закриття клавіатури прокручуванням і Return із зовнішньої клавіатури. Горизонтальний жест назад поглинає дотик до картки перед підтвердженням втрати чернетки. Нове натискання вкладки виконується під час попередньої анімації; стара анімація не скидає стан новішої.

## Нативна v003 — 1 листопада 2026

Обидва продукти використовують спільний сценарій: головна → сьогоднішній список → явний старт → вправа з усіма підходами. Перегляд іншої вправи, гайда чи історії не змінює поточну вправу в черзі. Галочки дозволені поза чергою. Після завершення поточної вправи відкривається наступна незавершена за актуальним порядком, із поверненням до початку списку за потреби.

Чернетка заняття відокремлена від шаблону. Вправи можна переставляти ручкою або кнопками вище/нижче; заміна доступна без виконаних підходів і зберігає планові параметри. Редактор шаблону має такі самі дії, а зберігає їх звичайною кнопкою збереження. Заміна скидає лише фактичні результати вибраної вправи; скасування пошуку нічого не змінює.

Ключ результату складається з ID входження вправи в заняття та номера підходу. Записи створюються лише для відредагованих або виконаних підходів: велика планова кількість не створює наперед масив результатів. Вага й повтори редагуються незалежно в кожному рядку, включно з виконаними. Зняття галочки зберігає введені значення. Вага зберігається в kg із відображенням у вибраних одиницях. Два входження тієї самої вправи мають незалежні результати.

Відпочинок показується компактною смугою над вправою та списком. Кожна нова галочка запускає відлік для відповідної вправи. +15 секунд продовжує реальний дедлайн; виправлення результату, зняття галочки, навігація та завершення відліку не перемикають вправу. Загальний час починається лише з явного старту заняття.

Остання галочка повертає до списку для перевірки. Збереження починається лише після явного завершення; раннє завершення, відмова від збереження, порожнє заняття, незмінний ID повторної спроби та атомарні записи залишаються підтриманими.

SwiftData-моделі, схеми, каталоги, seed stores, продуктові ідентичності й нативний YouTube-плеєр не змінені. Фізичне приймання на iPhone і перевірка VoiceOver ще потрібні. Скриншоти та xcresult залишаються локальними артефактами.

### Уточнення після перевірки на iPhone: клавіатура й початковий нуль

1 листопада 2026: додано кнопку «Готово» над клавіатурою в підходах, пошуку вправ, назві та числових полях редактора. Панелі вибору вправ і параметрів мають власний navigation host для клавіатурного toolbar; активна вправа має один toolbar для всіх рядків.

При фокусуванні нульової ваги очищається лише текст введення. Числове значення лишається нульовим; закриття без введення повертає `0`. Перші набрані цифри замінюють початковий нуль. Ненульові та помилкові значення не очищаються автоматично. Фактичне ручне стирання введеної ваги зберігає помилку валідації. Виправлення не змінює галочки й не перезапускає відпочинок.

Перевірка: 8 цільових Swift Testing тестів для кожної схеми; OnlyWeights UI-сценарії завершення, редагування й навігації перевірили закриття клавіатури в підходах, редакторі та бібліотеці/виборі вправ, збереження пошукового запиту й введення без початкового нуля. Прогін завершення повторено після виправлення програмного echo порожнього вводу SwiftUI. SwiftLint і перевірка меж: PASS. Debug build для фізичного iPhone: PASS; застосунок оновлено для ручного приймання користувачем.
